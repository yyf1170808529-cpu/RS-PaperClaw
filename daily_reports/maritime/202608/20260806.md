EYES OmniballAI Eye is a Python software product for structured multimodal perception and action-readiness assessment in autonomous systems. It combines observations from multiple sensing sources into a spherical operational view, allowing the evidence available for an intended action to be assessed before that action is accepted. The software makes sensing coverage, blind areas, sensor availability, operating constraints, provenance, and recovery options explicit parts of the decision process. Its central mechanism, the Active Observability Viability Covenant, evaluates whether an intended action is supported by sufficient observable evidence and a viable recovery path. When these conditions are not met, the action is represented as constrained, deferred, or not authorised. The release contains modular Python components for perception support, coverage evaluation, authority checks, safety constraints, provenance controls, recovery assessment, and domain adaptation. It includes executable source code, automated tests, release metadata, and checksum material so that the implemented behaviour can be inspected, verified, and reproduced. Verification material is included with the software release. The stated software behaviours are exercised by the included automated test suite, and all 36 automated tests in this release passed. The public GitHub repository provides the source code and verification material for independent inspection. EYES OmniballAI Eye is a working software product. It does not claim a completed physical hardware product, deployment within an operational autonomous system, regulatory approval, or safety certification. The software is intended to operate as a perception-support and action-readiness assessment layer within a broader autonomous-system architecture. It may be integrated with or applied to: Sensor-processing and sensor-fusion systems Robotics middleware Navigation and localisation systems Motion-planning and mission-planning software Simulation and digital-testing environments Safety supervisors and runtime-assurance systems Policy, permission, and action-authority engines Operator dashboards and human–machine interfaces Digital twins Fleet-management and remote-operations systems Drones and BVLOS operations Autonomous vehicles Industrial and mobile robotics Emergency response Maritime autonomy Space exploration The software also provides application profiles for heavy-duty vehicles, robotaxis and driverless shuttles, mining and construction equipment, humanoid service robots, perimeter systems, chemical-plant monitoring, and other autonomous operating contexts.
